# Implementación Taller de muralismo

Esta versión está enfocada en lectura, observación y trabajo en clase.

## Cambios principales

- Se quitó la sección de entregas realizadas.
- Se quitaron los módulos de envío, respuesta/reflexión y mis envíos.
- Se mantuvo el material visual de la guía dentro de cada sesión.
- Se ajustó el lenguaje para estudiantes.
- Se agregó una presentación del curso más clara para el inicio.
- Se agregó el apartado de preparación de superficie en la sesión 4.
- Se agregaron botones de navegación entre sesiones.
